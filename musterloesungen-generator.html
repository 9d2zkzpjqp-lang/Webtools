Mathe-LK – Musterlösungs-Generator

Bilder auswählen, Seite und Aufgabe eintragen, sortieren lassen und eine einzige eigenständige HTML-Datei erzeugen.

Wird in der erzeugten Seite angezeigt.
Freie Eingabe, z. B. 2026/27 oder 2026.
Noch keine Bilder ausgewählt.
Die Bilddateien werden nur lokal im Browser verarbeitet. Diese App enthält keine Upload-Funktion und keine externen Bibliotheken.
    Die erzeugte Datei enthält CSS, JavaScript und alle Bilder direkt eingebettet und kann unmittelbar auf GitHub Pages veröffentlicht werden.
